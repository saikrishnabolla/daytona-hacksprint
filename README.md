# Pentests

AI security testing for small development teams. Pentests runs apps in Daytona sandboxes, scans them with OWASP ZAP and checks suspected bugs in a browser.

[Presentation (PDF)](docs/presentation.pdf)

The platform is in [`platform/`](platform/). The test app is in [`demo-repo/`](demo-repo/). Configure server credentials using [`platform/.env.server.example`](platform/.env.server.example).
